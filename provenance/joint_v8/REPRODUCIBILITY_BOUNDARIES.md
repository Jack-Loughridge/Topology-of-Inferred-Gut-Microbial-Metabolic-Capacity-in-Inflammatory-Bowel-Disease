# Reproducibility boundaries of the final joint comparison

The completed result is the regularised v8 experiment, with 25 joint and 25 matched control models and no finite-budget approximations. Public aggregate checks reproduce means, sample SDs, paired differences, class totals and confusion-derived accuracy, balanced accuracy and macro F1.

They do not independently reconstruct AUC ranks, individual log likelihoods, production gradients or private split membership. The review export omits individual probabilities, fitted models, the exact per-fold interval boundaries and its complete executed source manifest. Do not infer realised interval counts or a mean alpha profile from the requested M=32 setting or the min/max alpha summaries.

The frozen delivered source package has an intact 28-payload manifest and matches the described statistical and numerical conventions. `END_INTEGRITY.json` in the original private review archive reports unchanged execution files. It does not, by itself, prove byte identity between every executed VM source file and the delivered package. Retain the original VM package manifest, run identity, per-job intervals, models, prediction records and locked partitions for the final reproducibility deposit. No new fitting run is required merely to retain them.

The production preflight deliberately depends on the original orchestrator configuration, source lock, faithful Ricci matrix, raw H0 diagrams, metadata and all historic partition receipts. These are not supplied by a clean clone. Do not bypass the checks or fabricate a missing lock file to make the runner appear self-contained.

The graph scaffold, support references and Ricci axis were constructed using the source cohort before splitting. V8 leaves that upstream design unchanged. Train-only intervals and scalers do not convert it into a wholly fold-isolated graph reconstruction.

The source, aggregate outputs and deterministic table generator can be checked without rerunning the model. An immutable software tag, DOI, complete derived-data access arrangements and the exact executed-source receipt remain final release tasks.
