# Graph-diagnostic figures

This directory contains the canonical manuscript copies produced by the
promoted active-outdegree and active-edge weight-density generators.

- `outdegree_hist_active_participant_mean_cap6_excl0_with_sd.*` is the
  corrected participant-balanced active-outdegree figure and should replace
  the prior manuscript copy.
- `weight_density_curves_participant_average_clip099.*` and
  `weight_log_density_curves_participant_average_clip099.*` are the linear and
  log-density renderings. Their aggregate curves reproduce the prior numerical
  output to floating-point precision.

Both PNG and vector PDF versions are retained. The matching aggregate data and
run configurations are tracked under `results/figure_source_data/` and
`provenance/graph_diagnostics/`.
